# Design archive

Historical design documents preserved as-is. These describe the
journey of features that have since shipped (or been redesigned) and
are kept for reference.

The **current** design for the rollups feature lives in
[`../rollups.md`](../rollups.md).

The **current** design for the platform-services wiring lives in
[`../platform-architecture.md`](../platform-architecture.md). The
v0.2.2-era charter in `platform-services-completion-plan.md`
described the 3-PR sequence (PR-A AuditService, PR-B ModelService +
CatalogService, PR-C QueryService) that closed the four service stubs
(`AuditService`, `ModelService`, `QueryService`, `CatalogService`).
Those stubs are now wired in v0.3.0+, so the plan is historical.
